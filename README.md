# NESS Wardrobe

## Производительность

Версия 1.6.2 не меняет функции гардероба, а сокращает лишнюю работу интерфейса:

- создаётся только открытый раздел настроек, а не все разделы сразу;
- большая библиотека внешностей и список записей только с сайта показываются порциями;
- список записей только с сайта загружается лишь после открытия этого блока;
- неизменившаяся NESS Library не разбирается заново при каждом показе;
- проверка больших изображений не просматривает весь base64-текст;
- поиск, сортировка и справочники галереи повторно используются при порционной прокрутке;
- при запуске и сохранении одного наряда не выполняется лишняя повторная запись или полная нормализация всей библиотеки.

Все прежние возможности, интеграция с NESS Library, сайтом и ExtBlocks сохранены.

Самостоятельное расширение SillyTavern: переносимая галерея нарядов с персонами, персонажами, цветными тегами, генерацией по лорбуку и безопасной заменой описания одежды в уже написанном посте.

## Возможности

- три раздела: **Гардероб**, **Создать наряд**, **Настройки**;
- настройки организованы как браузерные вкладки с постоянной высотой окна и собственной прокруткой; на телефоне полоса вкладок прокручивается горизонтально;
- внутри создания — компактный переключатель **Написать / Сгенерировать**;
- заметный сегмент способа создания и отдельная кнопка **Новый черновик**;
- персонажи и NPC обозначаются ромбом `◆`, персоны пользователя — кругом `●` и пунктирной цветной меткой;
- персону или персонажа можно создать прямо внутри формы наряда; новая запись сразу выбирается для текущего черновика;
- теги ищутся по названию прямо в форме: Enter выбирает существующий тег, а для нового открывает компактное окно с уже заполненным названием и выбором цвета;
- теги, псевдонимы и имена показаны компактными цветными плашками без переноса слов; основные действия оформлены едиными заметными кнопками;
- закрепление нужных персон и персонажей отдельно для каждого чата;
- обложка и два дополнительных изображения шоукейса; изображения добавляются с устройства, по прямой внешней ссылке или из буфера обмена;
- цветные пользовательские теги, поиск и совместная фильтрация по нескольким тегам;
- ленивая отрисовка большой галереи и сжатие изображений до сохранения;
- просмотр настраиваемого количества последних постов и изменение только самого свежего найденного блока гардероба;
- чтение внешностей напрямую из общей NESS Library без изменения её ExtBlocks-профиля и сценариев;
- публикация внешности из NESS Library на сайте; записи, существующие только на сайте, остаются в отдельном второстепенном списке;
- отправка сохранённого наряда на сайт вместе с обложкой: недостающие персонаж и полка создаются автоматически, повторная отправка обновляет тот же наряд;
- отдельная вкладка активных нарядов из поста: редактирование, удаление с подтверждением и сохранение записи в библиотеку;
- замена существующего наряда требует подтверждения, новый персонаж добавляется перед маркером конца гардероба;
- одношаговая отмена последнего применения сохранённого наряда;
- пользовательское регулярное выражение выполняется только в отдельном Worker с общим тайм-аутом;
- выбор профиля из доступных профилей Connection Manager с автоматическим и прямым режимами;
- выбранный профиль сначала анализирует постоянные/сработавшие записи лорбука и последние два обычных поста, затем отдельным запросом создаёт наряд;
- промпты сканирования и генерации можно независимо изменить и вернуть к стандартным;
- плавающая круглая кнопка с единой иконкой одежды перетаскивается мышью и пальцем, позиции телефона и большого экрана хранятся отдельно;
- интерфейс использует цвета и штатные элементы активной темы SillyTavern, без собственной палитры и градиентов.

## Где хранятся данные

Библиотека, изображения, теги, персоны, персонажи, промпт и правило вставки находятся в `extensionSettings.ness_wardrobe`. Это серверные настройки SillyTavern, поэтому один профиль видит библиотеку с телефона и компьютера. Изображения перед сохранением уменьшаются и сжимаются.

Внешняя ссылка должна вести непосредственно на изображение и разрешать загрузку из браузера. Если сайт блокирует такие запросы, сохрани изображение на устройство или скопируй саму картинку в буфер обмена.

Закрепления текущего чата находятся в `chatMetadata.ness_wardrobe`. Они не смешиваются между чатами. Даты создания и изменения нарядов записываются в переносимом ISO-формате UTC.

Экспорт создаёт полный JSON-снимок библиотеки с изображениями. Закрепления чатов в него не входят, потому что уже хранятся в самих чатах.

Адрес сайта, логин и название репозитория сохраняются вместе с настройками расширения. Токен GitHub хранится отдельно только в браузере, где был введён, и не включается в резервную копию. На другом устройстве токен нужно ввести заново.

## NESS Library и сайт-гардероб

Основной источник внешности — опубликованная общая NESS Library (`sp_ness_master_library_v1`). Расширение не создаёт вторую копию библиотеки в собственных настройках.

1. Открой **Настройки → Библиотека**. Записи из NESS Library появятся первыми. Расширение только читает опубликованные общие данные и не меняет устройство ваших ExtBlocks.
2. Укажи адрес опубликованного сайта, например `https://логин.github.io/wardrobe/`, и нажми **Обновить данные сайта**. Внешности, которые есть только на сайте, показаны отдельно внизу.
3. Для отправки нарядов также укажи логин GitHub, репозиторий и fine-grained token с доступом только к этому репозиторию и правом **Contents: Read and write**.
4. Кнопка **На сайт** у записи NESS Library публикует или обновляет её в `wardrobe.json`.
5. У сохранённого наряда с обложкой нажми кнопку с облаком. Введи название полки и подтверди отправку. Если персонажа или полки ещё нет на сайте, расширение создаст их.

При публикации внешности постоянные теги из поля `base` записываются через запятую. Непустые отдельные поля добавляются через пустую строку с заголовками `THIGH MARKS`, `KNEE MARKS`, `SHIN MARKS`, `SHOULDER MARKS`, `FOREARM MARKS`, `NUDE UPPER`, `NUDE LOWER`. Разметка ракурсов и служебные поля библиотеки на сайт не переносятся.

Сайт должен использовать формат болванки: `wardrobe.json` в корне и папку `images/`. После отправки GitHub Pages может показывать прежнюю версию ещё несколько минут. Никому не передавай токен.

## Настройка вставки

Правило должно находить одну запись гардероба и содержать две группы:

- имя персоны или персонажа;
- нынешнее описание одежды.

Названия групп задаются отдельно. Поддерживаются как именованные группы (`name`, `outfit`), так и числовые (`1`, `2`). Перед сохранением правило можно проверить на последних постах: проверка показывает найденное поле, но не изменяет текст.

Для формата с угловыми скобками из примера уже задано стандартное правило:

```regex
⟦ОДЕЖДА:(?<name>[^⟧\r\n]+)⟧[ \t]*(?<outfit>[^\r\n]*(?:\r?\n(?!⟦(?:ОДЕЖДА:|/ГАРДЕРОБ⟧))[^\r\n]*)*)
```

Флаги: `gm`, группа имени: `name`, группа одежды: `outfit`.

В настройках также задаются шаблон новой строки с переменными `{{name}}` и `{{outfit}}` и маркер конца блока. При выборе карточки расширение:

1. проверяет указанное количество последних обычных постов и выбирает среди них самый свежий блок гардероба;
2. сверяет имя с именем и псевдонимами привязанной персоны/персонажа;
3. если запись уже существует, просит подтвердить замену и меняет только содержимое группы одежды;
4. если записи нет, добавляет её перед маркером конца гардероба;
5. проверяет, что чат и выбранный пост за это время не изменились;
6. сохраняет только этот пост и предлагает отменить последнее применение.

Вкладка **В активном посте** показывает записи именно из этого найденного блока. Их можно переключать как вкладки браузера, менять прямо в посте, удалять крестиком с подтверждением или переносить в библиотеку как новый наряд. При переносе персонаж выбирается автоматически, если имя совпало с его основным именем или псевдонимом.

## Генерация

Режим **Сгенерировать** использует профиль, выбранный в разделе **Подключение к модели**. Можно выбрать конкретный доступный профиль, автоматически использовать профиль, выбранный в SillyTavern, или обратиться к текущему подключению без Connection Manager. Список можно обновить, а профиль — проверить коротким запросом.

Работа разделена на два запроса к одному профилю:

1. промпт сканирования извлекает подтверждённые сведения из лорбука и последних двух постов;
2. промпт генерации получает этот разбор и создаёт название с готовым описанием одежды.

Результат не сохраняется и не вставляется автоматически: сначала он попадает в редактируемый черновик.

В промпте доступны переменные:

- `{{target}}`;
- `{{wishes}}`;
- `{{avoid}}`;
- `{{world}}`;
- `{{posts}}`;
- `{{scan}}` — результат первого этапа для промпта генерации;
- `{{current_date}}`.

## Установка

1. Поместите папку `ness-wardrobe` в `SillyTavern/public/scripts/extensions/third-party/`.
2. Полностью перезагрузите страницу SillyTavern.
3. Откройте гардероб круглой кнопкой 👗 или через **Extensions → NESS Wardrobe**.

## Ограничения проверки

Локальная проверка подтверждает структуру данных, поиск самого свежего блока в заданном диапазоне, добавление/замену/удаление записей, перенос JSON, наличие изолированного Worker, вкладки и отсутствие запрещённых цветовых схем. Она не заменяет проверку в конкретной установленной версии SillyTavern и с её темой/API.
