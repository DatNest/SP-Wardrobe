# Пустые шаблоны NESS Wardrobe

## Для ролевого поста — обычный текст
Скопируй содержимое `wardrobe-post.txt` в сообщение:

```text
[WARDROBE]
[/WARDROBE]
```

В настройках **Вставка → Как искать одежду → Обычные метки** укажи:
- **Начало блока:** `[WARDROBE]`
- **Начало записи:** `[LOOK:{{имя}}]`
- **Конец записи:** `[/LOOK]`
- **Конец блока:** `[/WARDROBE]`

При нажатии на сохранённый наряд в гардеробе расширение добавит запись с реальным именем и описанием одежды перед концом блока. Обычное сохранение наряда остаётся локальным.

## Для HTML
Скопируй содержимое `wardrobe-post.html` в текст сообщения. Параметры в том же режиме:
- **Начало блока:** `<section data-wardrobe="true">`
- **Начало записи:** `<look name="{{имя}}">`
- **Конец записи:** `</look>`
- **Конец блока:** `</section>`

Это буквально обрабатываемые фрагменты исходного текста. HTML-теги и комментарии в значениях не интерпретируются как регулярные выражения. Маркеры должны совпадать с исходным текстом сообщения, в том числе пробелами и регистром. Если в посте несколько похожих HTML-блоков, настрой **Начало блока**, чтобы выбрать нужный.

## Для сайта
`wardrobe.json` — это **отдельный** пустой каталог для сайта Wardrobe, а не для ролевого поста. Он содержит массивы `chars`, `cats`, `items`, `looks`. Публикация требует явного подтверждения и настроенного GitHub-токена.

Если твой пост уже использует собственные маркеры, менять его формат не нужно: скопируй соответствующие начало, конец записи и конец блока из существующего текста в настройки расширения. Прежний режим RegExp сохранён отдельно.
